# YMFF: Feature management made easy

YMFF is a nice little library that makes managing features with feature flags—and managing feature flags themselves—a bliss, thanks to Swift’s [property wrappers](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/properties/#Property-Wrappers).

## ⚠️ Deprecation Notice

As of April 2, 2026, this project is deprecated. No new features or bug fixes should be expected (although there is a small chance that this project will get a second life one day).
